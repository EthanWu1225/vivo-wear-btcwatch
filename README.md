# BTC Watch — 比特币行情（vivo 蓝河手表版）

> 一款运行在 **vivo WATCH GT 2（eSIM 版）** 上的实时比特币行情查看工具
> 基于蓝河操作系统 3.0（BlueOS 3.0）/ BlueOS Studio 构建

![主界面](preview/main.jpg)

**当前版本：v1.0（首次发布）** · 内部代号 v1.1.21 · 包名 `com.operit.btcwatch`

---

## ✨ 功能特性

| 功能 | 说明 |
|---|---|
| 📈 **实时行情** | 大字号价格，涨跌幅 / 24h 最高 / 24h 最低 / 成交额一屏可见，5 秒自动刷新 |
| 🕯️ **实时蜡烛图** | 打开即补齐最长 **24 小时**历史（49 根 × 30 分钟）；历史拉取失败时自动进入 **自攒模式**（48 根 × 2.5 分钟 = 2 小时窗口） |
| 📈 **MA7 均线** | 蜡烛图 + 日K 均带 7 周期均线与 24h 基准线 |
| 📊 **日K线图** | 以持有比特币的港股标的（03066.HK）为代理数据源，自动适配交易日 |
| ⚙️ **个性化设置** | 振动提醒开关、配色方案（绿涨红跌 / 红涨绿跌）、刷新间隔可调 |
| 📳 **振动反馈** | 价格异动振动提醒，可在设置中关闭 |
| 🎛️ **表冠交互** | 旋转表冠切换视图，已做聚焦适配 |
| 🛡️ **容错机制** | 请求看门狗 + 指数退避重试 + 单轮请求数严格限制（≤ 2） |

## 🔧 技术要点

### 开发范式

- 类 Web 技术栈：`.ux` 单文件组件 = `template` + `script` + `style` 三段式
- 生命周期与 Vue 类似，但**自定义方法不能写进 `methods` 对象**（会白屏）
- `script` 段为模块模式，所有工具函数需显式导出

### 联网策略（核心难点）

手表侧网络环境对境外域名与 HTTPS 通道不稳定，实测后收敛出以下策略：

| 问题 | 方案 |
|---|---|
| 境外域名 DNS 不可靠 | **IP 直连 + Host 头 + 明文 HTTP** 组合（实测唯一长期可用通道） |
| HTTPS / 域名通道 | 实测失败（错误码 fail-6），已从数据链路移除 |
| 无效 IP 导致卡死 | 剔除返回 301 的 IP，只保留实测可用的节点 |
| 同一 IP 同端口两类请求互挤 | 启动时历史请求**抢跑**，行情延后 2.5 秒启动 |
| 并发压力导致系统假死 | **单轮请求数 ≤ 2**，串行发送 |
| 历史接口无响应 | 请求看门狗（15s）+ 最多重试 2 次 |
| 历史彻底不可用时 | 自动降级为**自攒模式**（用 5 秒 ticker 自行合成 2.5 分钟 K 线） |

### 数据源

| 数据 | 来源 | 说明 |
|---|---|---|
| 实时行情 | Gate.io ticker（IP 直连 + HTTP） | 从早期版本至今唯一从未失效的接口 |
| 蜡烛历史 | Gate.io candlestick（30 分钟粒度 × 49 根） | 成功时提供 24 小时窗口 |
| 自攒 K 线 | 由 ticker 累积合成 | 历史失败时的保底方案，本地持久化 |
| 日K线 | 03066.HK（港股比特币代理标的，腾讯 / 东财双源） | 受港股交易时段影响 |

## 🚀 安装方法

### 方式一：轻腕社区安装

在轻腕社区搜索「**比特币行情**」，下载安装到手表即可。

### 方式二：本地侧载

1. 使用 **BlueOS Studio** 打开工程目录
2. 连接手表（开启 USB 调试）
3. 点击「运行」或「构建」生成 `.rpk` 包
4. 侧载安装到手表，首次启动即可看到实时行情
