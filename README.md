# BTC Watch —比特币行情（vivo蓝河手表版）

一款运行在 vivo WATCH GT 2 (eSIM) 上的实时比特币行情查看工具。

![preview](preview.jpg)

## 核心功能
- 实时行情（美元/人民币、涨跌幅、今高今低、今开）
- 1 分钟分时蜡烛 + 30 分钟 K 线（双通道互补：腾讯分时 + Gate v2 蜡烛）
- 日 K 线（港股 FA南方比特币 ETF 代理）+ MA7
- 表冠切换视图（实时 → 日K → 设置）
- 振动提醒（涨跌幅阈值触发）
- 配置持久化（颜色方案、刷新间隔、振动开关）
- 重启后曲线仍在（采样落盘）

## 适用机型
- vivo WATCH GT 2 (eSIM) /蓝河 OS 3.0
- 屏幕466x466，方形表盘

## 开发笔记（避坑总纲）
详见仓库内 `开发笔记.txt`，关键点：

1. 联网只能用「国内 IP + Host 头 + 明文 HTTP」或「境内 HTTPS 域名」——境外域名解析会被手表 DNS 拦
2. eSIM 首次 DNS+TLS 常超 4.5 秒，所有"补历史"请求的看门狗建议12 秒
3. 多源解析必须「万能扫描」：不管后端返回是 JSON 对象还是字符串，都能吃
4. 重试必须「成功就置标志」—— 否则每 5 秒无限重试会把服务器打成限流
5. 交付前必过「结构深度=0 + 模块模式 node --check + assert 计数」三道关口
6. 补丁脚本禁止按行号切片替换（本项目真凶就是误删一个 `}` 导致整页白屏）
